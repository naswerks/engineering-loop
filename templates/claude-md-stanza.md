## Start here — before any work

This repository's working knowledge lives in `docs/`. Before any non-trivial work, read these two docs
to situate yourself, then the task-relevant docs they point you to:

- `docs/_meta/doc-index.md` — the menu of living docs; pick the 2–3 that match the task and read them.
- `docs/_meta/docs-workflow.md` — how knowledge flows through `docs/` (the loop, the folders, the templates).

The loop's skills are the `naswerks` plugin (`docs-*` for knowledge, `spec-*` for execution, `init` for
this shape). Docs marked `status=draft` were scanned, not decided — read them as a starting point and
promote them to `status=current` as you confirm each section.
