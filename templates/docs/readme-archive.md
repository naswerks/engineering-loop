# archive/

Completed or abandoned efforts, grouped into topic folders. Write-once: frozen history, never edited — a
stale reference in an archived doc is the record of what was believed at the time. A spec-driven effort
archives in the split shape (`project-status.md` at the root, `specs/`, `implementation/`,
`sessions/`); a small effort is flat. `archive/audit/` is the one exception to topic grouping: audit
reports sit beside the living docs they audit, and the cross-cutting health report sits at its root.

A README in this folder is never a queue entry.
