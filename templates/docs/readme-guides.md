# guides/

How to ADD a new thing — step-by-step walkthroughs (a new service, a new app, a new worker). Prescriptive:
the guide is the decided way, and code conforms to it. Patched by `docs-process` when a session changes
the way; audited by `docs-audit-feature` for whether the code still follows it.

A README in this folder is never a queue entry.
