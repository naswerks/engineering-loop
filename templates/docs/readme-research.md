# research/

The running tab of ideas not yet built. `docs-backlog` creates a research doc here; a spec pipeline lives
in `research/{topic}/` (the ignition brief — the coordinator's spec and the charter every seat reads — one
numbered spec per build seat, the tracker, the live-checks). A research doc stays here through the build — however many sessions and working docs that
takes — and is archived WITH its working docs by `docs-process` when the effort finishes. The folder is
the queue; nothing here is done.

A README in this folder is never a queue entry.
